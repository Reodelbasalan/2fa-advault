How to use Vault

Add a two-factor account once, then get its code with a tap for good. Here's the whole thing, start to finish.

What you'll need

One thing: the setup key from the account you want codes for. It's the long code an app screen shows when you turn on an authenticator — usually behind a “Can't scan it?” link under a QR code. It looks like JBSW Y3DP EHPK 3PXP.

Not the same as: the 6-digit code (that expires in 30s), a backup/recovery code (one-time use), or your password. It has to be the setup key.

Two ways to use it

One-off

Quick code

On the front page. Paste a secret, press Get code, copy. Nothing is saved. Use this for a secret you were handed once and don't want left in the browser.

Everyday

Save to vault

For accounts you open all the time. Add it once and it lives on a card that refreshes every 30 seconds — one tap copies the code, no more pasting the long secret each login.

Step by step

  1. 1

    Find the setup key

    In the account's security settings, choose Authenticator app. When the QR code appears, tap Can't scan it? (or “enter this text code”). The long key that shows up is what you need.

    Gmail: myaccount.google.com → Security → 2-Step Verification → Authenticator.

  2. 2

    Open Vault and add it

    Press Add account, paste the key (spaces and lower case are fine), or paste the whole otpauth:// link and the name fills itself in.

  3. 3

    Check the preview, then save

    A live code shows in the preview. If it matches the account you're setting up, press Save to vault. If it stays blank, the key was mistyped.

  4. 4

    Use it from then on

    The account is now a card. Tap it to copy the current code; the ring shows how many seconds it has left before it changes.

Want to test it first?

Use this public test key — it's from the standard itself, so it's safe to try with nothing at stake:

JBSWY3DPEHPK3PXP

Add the same key to Google Authenticator on your phone and to Vault. If both show the same six digits at the same moment — and change together every 30 seconds — it works.

Good to know

Adding it here doesn't remove your old way in

An authenticator is added alongside your phone number and other recovery options — it doesn't replace them. You keep every way back in you already had.

Saved accounts stay on this device

They live in this browser only. Open Vault on your phone and your laptop and you'll have two separate lists — there's no sync.

Never share a setup key

It isn't a password — it's your 2FA itself, for good. Anyone who sees it can generate your codes. Don't screenshot it or send it to anyone. If it leaks, remove the authenticator and set it up again for a fresh key.

That's it.

Add your first account and you're done.
